## 🚀 Featured project

### [Multi-Modal Attendance System](https://github.com/sneghaganesh3-rgb/multi-modal-attendance-system)
Biometric attendance that fuses **face recognition**, **palm biometrics** and **WebAuthn fingerprint** into one score, with server-side liveness checks to resist photo and replay spoofing. Includes class sessions, a student portal, notifications and CSV/PDF reports.

`FastAPI` · `React` · `PyTorch` · `MediaPipe` · `OpenCV` · `SQLite`
